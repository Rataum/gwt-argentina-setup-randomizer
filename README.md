# GWT Argentina Setup Randomizer
Gerador de setups aleatórios e reprodutíveis para Great Western Trail: Argentina — PWA feito com React, TypeScript e Vite, com seed compartilhável por link, funciona offline e roda 100% no navegador (sem backend).

Para acessar utilize o link https://rataum.github.io/gwt-argentina-setup-randomizer/
